# Security reporting

Report vulnerabilities privately using the repository's GitHub **Security → Report a vulnerability** feature when enabled. Otherwise contact the repository owner privately; do not include personal collections, tokens or private keys in public issues.

Public deployment is not enabled automatically. Keep the OIDC provider, reverse proxy, SDK and dependencies updated. Revoke exposed credentials immediately and rotate any affected signing/service keys. Disabling a local sync switch does not delete remote copies or exported files; use the explicit deletion and authorization controls.
