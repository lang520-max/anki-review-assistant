# 隐私与安全

- 默认只在手机应用私有目录存储；关闭 Android 自动备份。无需 Root、全盘文件访问或 AnkiWeb 登录。
- Anki 授权可能是读写合并权限，但程序不调用插入、更新、删除、调度回答或同步 Anki 的接口。CI 有静态边界检查。
- 导出文件只能通过系统文件选择器由用户选择；临时数据库只读打开。原文件和 Anki 数据库不修改。
- 云同步默认关闭。用户主动登录、选择牌组、开启授权后才提交后台任务。笔记正文另设默认关闭的开关。
- 访问和刷新令牌使用 Android Keystore AES-GCM 加密。APK 无服务器秘密。私有检查点包含用户选择上传的学习数据，存储于应用内部目录。
- OAuth 公共客户端采用 PKCE、随机 state 和十分钟授权回调有效期。凭据不会出现在 URL、源码或日志中。
- 服务端验证 JWT 签名、issuer、audience、过期时间和权限，并在线 introspection 检查令牌活跃状态；授权服务不可达时拒绝请求。
- MCP 仅能读取自身用户的数据，没有上传、删除或 Anki 写入工具。REST 上传和删除需独立权限。
- 云端数据库及备份应使用宿主机／托管存储加密；Docker 示例不声称自动提供磁盘加密。默认不开启请求访问日志或正文日志。
- 远程删除保留集合 ID、owner 和版本墓碑，不保留学习正文；已生成的备份按部署者保留策略到期删除。删除实时数据库不能撤回已经手动导出的 JSON 或已经发给 ChatGPT 的内容。
- 本机断开会清除凭据并取消上传任务；若需使其他会话失效，到 Keycloak 账号管理中撤销会话／离线授权。服务端在线检查配合撤销生效。

请勿将真实牌组、导出文件、访问令牌、`.env`、签名私钥提交到仓库。所有自动测试仅使用合成数据。正式开放公网之前应完成依赖漏洞扫描、TLS、备份恢复、授权撤销与真实客户端的部署验收。
