# 指标定义与局限

所有日期范围包含起止学习日。默认设备 IANA 时区、凌晨 4 点换日，可设置。该设置属于助手口径，不能从缺失的 API 元信息中推断用户 Anki 设置。按本地墙上时间划分，覆盖夏令时跳变。

| 指标 | 定义 |
|---|---|
| 复习次数 | `type` 为 0（学习）、1（复习）、2（重新学习），且 `ease` 为 1—4 的事件数 |
| 不同卡片 | 范围内有效事件的 card ID 去重数 |
| 首次观察到的新学笔记 | 整份已导入历史中最早学习事件所在学习日，按 note ID 去重；不等同于唯一英语单词或有完整历史保证的首次学习 |
| 学习时间 | 有效事件 `timeMs` 之和；可能受 Anki 计时上限影响，不是手机使用总时长 |
| 平均耗时 | 有效事件总耗时／事件数，无事件返回未知 |
| 连续天数 | 今天有学习时从今天回溯，否则从昨天回溯；仅基于已导入历史 |
| 观测复习成功率 | 常规复习 `type=1` 中 `ease=2/3/4` 的比例，Hard 也算回忆成功；不是 FSRS 预测保持率 |
| 年轻／成熟 | 按复习前 `lastInterval`，不足 21 天／至少 21 天；负间隔为秒，属于不足 21 天 |
| Again 排行 | 有效事件中 `ease=1`，按 note 聚合，保留所有相关 card ID；不同笔记即使正文相同也不擅自合并 |
| 卡片遗忘 | 区分原始卡片 `lapses` 与历史内 Again 次数；两者不能互换 |
| 待复习／积压／未来负担 | 结合队列、集合创建时间、助手换日设置的快照估计；新卡 due 是顺序，不当作日期；排除筛选牌组、挂起、埋藏及预览 |

手动调度、筛选／预览与未知类型不进入成功率或常规每日统计；MCP 详细历史保留其原始记录。Provider 缺 revlog 时历史指标是“不可用”，不返回虚假的零或精确保持率。

历史牌组筛选使用卡片当前归属，不代表复习发生时的牌组。删除卡片的历史仍可贡献全部牌组的复习次数，但缺少笔记关系时不参加词排行。历史不完整时，所有趋势均只代表观察窗口。

本版展示每日次数／耗时与窗口成功率、年轻／成熟表现、遗忘排行及未来已排定负担。不实现 FSRS 训练或给出精确新词处方；是否暂停新词等建议应结合数据覆盖和个人时间预算，不能伪装成精确调度结论。
