## 规则

适用于启用分流规则、指定原牌组及其子牌组中的受管理卡片：

| 所在阶段 | 作答 | 处理 |
| --- | --- | --- |
| 尚未进修复组 | Again | 本轮进组计数 +1；达到5时移入修复组 |
| 尚未进修复组 | Easy | 抵消已有的1次Again，最低0 |
| 尚未进修复组 | Hard / Good | 计数不变 |
| 修复组内 | Easy | 连续Easy +1；连续5次返回原组 |
| 修复组内 | Again / Hard / Good | 连续Easy归零；Again仍单独记录 |

例如 Again、Again、Easy 后计数为1。Easy、Easy、Again 后也为1；不预存抵扣。按原卡片独立、按作答顺序处理本轮累计，不限7天，不跨卡抵消。正常学习、重学、复习和可重新排程的筛选牌组答题适用；仅预览不计数。失败或重复提交不再次抵消，原生撤销/重做同时恢复计数与作答。

保留旧版0–9次计数、修复进度及原始历史；从更新后的真实作答开始采用新规则，不追算旧Easy，不启动批量搬移。已有高于门槛的旧计数逐次减少，仍只在实际按Again时检查进组。返回原组后下一轮从0开始。仅改变独立分流计数，不改写原始评分、复习日志或FSRS排程。

网站的“7日净薄弱”只是时间窗口统计，与手机本轮进组计数不同；刷新网站不能改变手机规则，必须覆盖升级同包名、同签名的AnkiDroid分流测试版。不要先卸载；按既有更新流程保留本机备份并由用户在系统安装页面确认。
