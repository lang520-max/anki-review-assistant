# 手机安装与使用

## 下载 APK

1. 手机浏览器登录拥有仓库访问权限的 GitHub 账号，打开仓库的 **Actions**。
2. 选择 **Android APK** 中成功（绿色）的运行，向下找到 **Artifacts**。
3. 下载 `anki-review-assistant-debug-…` ZIP 并解压，安装 `app-debug.apk`。
4. 按 Android 提示允许当前浏览器或文件管理器安装该应用。无需 Root。

产物附带 SHA-256 和提交标识。Debug APK 仅用于测试，各次 CI 的临时签名可能不同，暂不保证覆盖升级；卸载前先导出数据。正式签名工作流需要私人 GitHub Secrets，尚未配置时不会发布正式 APK。

## 连接 AnkiDroid

先打开 AnkiDroid，完成首次设置并进入已有集合。回到助手首页授权读取，再点“读取当前 AnkiDroid 数据”。Android 底层权限名称可能包含“读写”，本项目代码仅查询。

当前仅自动发现标准版 `com.ichi2.anki`。并行包、自定义包名及不可见 Provider 不承诺支持。旧版本可以读取牌组、笔记；不支持的卡片接口或字段会显示限制。

## 导入详细历史

在 AnkiDroid 导出已有集合或牌组，开启其版本提供的学习进度／调度信息选项；确认导出含 revlog。助手“同步”页选择 `.apkg` 或 `.colpkg`。不需要媒体。导出选项随 AnkiDroid 版本变化，未包含学习记录的文件不会凭空产生历史。

默认每次导入创建独立来源。更新同一集合时，先选中旧来源，勾选“重新导入当前集合”，再选择该集合的新导出文件。它会完整替换旧副本，既避免重复，也反映导出中已经撤销或删除的事件。不要将其他集合覆盖到当前集合。

支持 `collection.anki2`、`collection.anki21` 和 Zstandard `collection.anki21b`。数据库版本仅接受明确支持的 11/16/17/18；结构不兼容时停止并保留旧缓存。单次文件和解压后数据库上限各 512 MiB，10 万笔记、20 万卡片、100 万事件；大型集合建议分牌组导出。手机可用内存可能进一步限制可处理规模。

## JSON 备用路径

同步页导出 JSON，默认不包含笔记正文；如需分析具体词，可主动勾选。文件包含学习数据和内部 ID，保存在你选择的位置。可以手动提供给支持文件分析的客户端，不需要 MCP 或云服务。

## 首次真机验收

- 未安装时显示正确状态；安装后授权成功／拒绝／撤销都不崩溃。
- 读取现有牌组并核对 ID、数量；确认 AnkiDroid 卡片与调度未变化。
- 导入一个含学习记录的小牌组，核对三条已知回答的按钮和耗时。
- 重复导入同一来源，统计不翻倍；离线重启仍能查看缓存。
- 导出 JSON 后确认正文开关生效。

CI 模拟器覆盖合成历史文件与启动界面。真实 AnkiDroid 版本、手机厂商权限行为和真实牌组尚需按此清单验证。
